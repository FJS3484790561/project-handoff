# 产品与需求

让一个人在公司、家里的两台电脑交替开发同一 Git 项目，新会话能根据仓库文档恢复工作，不依赖旧聊天。

## 本期范围

- brainstorm-lite：独立需求头脑风暴，输出简明需求文档，结束后正常开发。
- project-handoff：初始化规则、需求、架构和状态文件；开工拉取后重读；收工更新文档并提交推送。
- Git 脚本核实远端提交，保留未提交工作，拒绝分叉覆盖和强制推送。
- 两台电脑可各自安装技能，也可将技能放进业务仓库。
- 发布为公开 GitHub 仓库，使用说明集中在 README.md。

## 不做

不引入记忆服务、MCP、数据库、后台守护进程，不强制详细计划、TDD、子代理、worktree、PR 或发布流程。UI 交给用户自己的规则。

## 验收

本地 bare 仓库与两个独立工作区完成双向交接；新工作区取得相同代码和状态文档；推送失败保留提交；脏工作区和分叉不被覆盖；安装可重复、更新先备份。公开远端提交可核实。
