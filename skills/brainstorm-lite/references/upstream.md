# 来源与修改

本技能改编自 [obra/superpowers 的 brainstorming](https://github.com/obra/superpowers/blob/main/skills/brainstorming/SKILL.md)，参考日期 2026-10-18，MIT 许可。

保留：场景驱动提问、需求边界、标明推断、简明设计文档。

移除：自动转入 writing-plans、强制子代理审核、完整工作流约束、内建 visual companion。UI 遵循用户已有规则。

这是独立维护的适配版本，不自动跟随 Superpowers 更新，不是其官方发行版。要避免重复触发，在所用客户端停用完整 Superpowers 插件；本安装器不会修改其他插件。
